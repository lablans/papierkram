# PrivateAIM — Privacy-Preserving Analytics in Medicine

PrivateAIM develops FLAME (Federated Learning and Analytics in Medicine), a next-generation federated platform for machine learning and data analysis within the German Medical Informatics Initiative (MII). The core principle is that analyses move to the data, not the data to the analyses: algorithms run locally at each Data Integration Centre (DIZ) without raw patient data ever leaving its home institution. FLAME combines state-of-the-art federated learning methods with modern privacy models (differential privacy, secure multi-party computation) for multimodal clinical data, and integrates monitoring and control components that enable easy adoption by hospital IT departments. UMM contributes to AP3 (platform development) and AP4 (DIZ integration and roll-out).
